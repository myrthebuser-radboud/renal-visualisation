# Renal Visualisation

## Overview

Renal Visualisation is a web-based application for interactively exploring 3D models of renal anatomy.

The application displays 3D models exported in the GLB format, allowing users to explore anatomical structures in a browser without installing additional software.

The visualisation is designed to provide an accessible and intuitive way to view the spatial relationships between the kidney, lesions, and surrounding vascular structures.

## Features

- Interactive 3D model visualisation directly in a web browser.
- Support for GLB models.
- Rotate, zoom, and explore the model from different angles.
- Visual distinction between anatomical structures using separate colours and materials.
- Additional information panels to explain the displayed structures.
- Orientation assistance to help users understand the model's spatial positioning.
- Responsive web interface.
